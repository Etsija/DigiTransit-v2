Evaluation Guide

Type legibility at a glance
Can you instantly tell bus vs. tram vs. train without reading any text?
A — strongest (icon + colour)D — good (icon)B — subtle (glow + badge)C — minimal (badge only)
Glass aesthetic purity
Which feels most like Dark Sky's "floating cards over a map"?
C — purest glassB — strong glassD — cleanA — most opaque (solid strip breaks the glass)
Information density
Which fits the most stops on screen comfortably?
B, C — most compactD — same width, icon uses vertical spaceA — strip costs horizontal width
v1 familiarity
Which feels like a recognisable evolution of what you built?
A — closest to v1 patternD — same icon concept, modernised
Hybrid option
B + D is a natural combination: luminous left edge glow and small icon badge inside the card. Stronger type signal than B alone, lighter than A.
